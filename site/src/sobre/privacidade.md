# Política de Privacidade

**Atualizada em:** 1 de maio de 2026

O **Catálogo de Políticas** (iniciativa Rede EJA e Inclusão Produtiva — FRM, Fundação Bradesco, IESP-UERJ e parceiros) **não coleta dados pessoais identificáveis** dos visitantes.

## Dados que coletamos

Usamos o serviço [GoatCounter](https://www.goatcounter.com/) para análise agregada de tráfego. O GoatCounter:

- **Não usa cookies**
- **Anonimiza endereços IP** (não armazena IP completo)
- **Não rastreia visitantes entre sessões**
- **Coleta apenas:** página visitada, página de origem (referrer), navegador e país (derivado do IP anonimizado)

Esses dados são usados exclusivamente para entender padrões agregados de uso e melhorar o catálogo.

## Logs de servidor

O GitHub Pages, plataforma onde este site é hospedado, mantém logs de servidor anonimizados conforme [política do GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

## Transferência internacional

Este site é hospedado em servidores do GitHub (Microsoft) localizados nos **Estados Unidos**. O GoatCounter opera em servidores na **União Europeia**. Conforme LGPD art. 33, declaramos essa transferência internacional para fins de transparência.

## Base legal (LGPD)

O tratamento de dados acima é fundamentado em:

- **Art. 7º, IX:** legítimo interesse — análise estatística agregada para melhoria do serviço público
- **Art. 7º, II:** cumprimento de obrigação legal — Lei de Acesso à Informação (Lei 12.527/2011)

## Seus direitos (LGPD art. 18)

Como o site não coleta dados identificáveis, não há registros pessoais para exercer direitos de acesso, correção ou exclusão. Para qualquer dúvida, abra uma [issue no GitHub](https://github.com/antrologos/catalogo-politicas/issues).

## Política de retenção

- Dados agregados do GoatCounter: retidos por **18 meses**
- Logs do GitHub Pages: conforme política do GitHub

## Encarregado de Dados

A figura formal de Encarregado de Dados (DPO) será nomeada caso o tratamento de dados seja ampliado. Atualmente, contatos podem ser feitos via [issue no GitHub](https://github.com/antrologos/catalogo-politicas/issues).

## Atualizações

Esta política pode ser atualizada periodicamente. A data no topo indica a última revisão.
