## TOP 10 padrões a IMPORTAR para o schema/vocabulário AGORA

| # | Padrão observado | Regra de produção a adotar AGORA |
|---|---|---|
| 1 | URL persistente e bookmarkável (CELEX, OECD, GovTrack) | Schema com `slug` único e estável; pipeline gera por regra determinística; mudança de slug = `redirect_from` |
| 2 | Toda ficha tem fonte clicável (Planalto, gov.br) | Schema obrigatório: `fonte_url` (HTTPS validada), `fonte_tipo`, `fonte_data_acesso`, `fonte_arquivo_path` (snapshot local) |
| 3 | Badge de qualidade de metadados (data.gouv.fr) | Campo computável `completude_pct` (0-100) calculado pelo pipeline |
| 4 | Comparação requer unidade coerente (Atlas Brasil, OECD) | Vocabulário canônico OBRIGA `unidade_medida` controlada (ex.: BRL/mês, % população, beneficiários/ano) |
| 5 | Citação acadêmica formatada (OECD, World Bank) | Schema deriva `citacao_apa` e `citacao_bibtex` por política, com `data_versao_catalogo` |
| 6 | Tesauro hierárquico EuroVoc (21 domínios, 127 sub) | Toda categoria/tema com: ID estável, label PT, label EN (futuro), descrição, `parent_id` |
| 7 | EUR-Lex versiona consolidações com diff | Schema com `versao` e `data_validade_inicio/fim`; política revogada vira `status: revogada` com link sucessora |
| 8 | Filtros facetados exigem valores controlados | Toda coluna filtrável (esfera, eixo, modalidade, público-alvo) com vocabulário canônico fechado; schema rejeita fora-da-lista |
| 9 | Catálogos vivos (GovTrack, CourtListener) com timestamps | Schema obrigatório: `criado_em`, `atualizado_em`, `revisado_por`, `proxima_revisao_prevista` |
| 10 | Acessibilidade declarada (gov.uk, EUR-Lex) | Todo texto longo tem versão `descricao_simples` + `descricao_tecnica`; garante WCAG e usabilidade cidadã |

**Bônus**: padrão "ID estável universal" (CELEX) sugere identificador interno do projeto imutável (ex.: `FRM-CP-2026-EDU-0001`), separado de IDs externos.

## TOP 5 features inspiradoras (com URL precisa)

1. **EUR-Lex — CELEX como ID universal + deep linking** (eur-lex.europa.eu) — Cada doc tem ID universal (ex.: `32016R0679` = GDPR) que é URL fragment + citação acadêmica + chave API simultaneamente.
2. **CourtListener — Authorities + Citator + 3 tipos de alertas** (courtlistener.com) — Cada decisão mostra (a) o que ELA cita e (b) quem a cita DEPOIS. **Importar**: ficha de política deve listar relações tipadas (substitui/altera/regulamenta/citada-por).
3. **data.gouv.fr — badge de qualidade visível no card** — Mostra "Bon 100%" ou "À améliorer 44%" antes do clique. **Importar**: transparência radical de QA.
4. **OECD GPS — rede visual navegável de políticas** (gpseducation.oecd.org/revieweducationpolicies) — Política como grafo. **Importar**: prototipar visualização em rede no Bloco E.
5. **GovTrack.us — alertas granulares por subject/committee/member** — **Importar**: schema com TAGs e VOCABULÁRIO suficientemente granulares para alimentar sistema de alertas.

## TOP 5 anti-padrões a evitar

1. **Planalto** — links externos sem snapshot e sem responsividade. Lição: **guardar snapshot local + indicar versão consultada**.
2. **MDS** — fragmentação em subdomínios sem design system. Lição: **catálogo único com URL canônica**, independentemente da fonte.
3. **gov.br/serviços** — paginação cega sem contadores nem filtros facetados. Lição: **todo filtro mostra contagem ao vivo ANTES do clique**.
4. **ObservaSampa / Atlas Violência** — sem citação acadêmica formatada visível. Lição: **botão "Copiar citação APA/ABNT/BibTeX" em CADA ficha desde dia 1**.
5. **Catálogo IPEA** — homepage não exibe contagem total nem destaque de fichas. Lição: **home mostra "439 políticas | 9 estados+Federal | última atualização DD/MM/AAAA" + 3-5 fichas em destaque**.

**Bônus**: sites que usam só categoria (sem busca textual livre) = força adivinhação. **Nossa busca tem ambos**.

## 7 wireframes prioritários para Bloco E

1. **Home / Dashboard agregado** — combinar "estado do catálogo" GovTrack + KPIs Atlas Violência + cards "fichas em destaque" + busca proeminente gov.uk.
2. **Página de busca/listagem com filtros facetados** — sidebar EUR-Lex Advanced Search com **contador ao vivo por faceta**. Cards estilo data.gouv.fr com badge de completude.
3. **Ficha individual** — cabeçalho OECD CountryProfile (IDs/datas/citação) + bloco Authorities/Citator CourtListener (políticas relacionadas) + texto integral embedado EUR-Lex + botão "ver no Planalto" externo com data captura.
4. **Comparação lado-a-lado N políticas** — Atlas Brasil PNUD (selecionar 2-N, tabela + gráfico). Unidades coerentes.
5. **Mapa coroplético** — Atlas Violência / ObservaSampa (Brasil → estado → município/distrito), seletor indicador + ano (timeline).
6. **Timeline / cronologia** — "Linhas do tempo" IPEA + interatividade Open Policy Canada. Filtros por esfera e eixo.
7. **Página "Como citar / Sobre os dados"** — OECD methodology + EUR-Lex About + badge governança. Inclui versionamento, metodologia, equipe, contato, licença CC, link repo aberto.

**Avançado (Bloco E+)**: alertas email/RSS GovTrack/CourtListener; API pública data.gouv.fr/EUR-Lex; "Benefit Finder" wizard USA.gov se virar ferramenta para gestores.
