## 3. Marco legal BR — síntese para scraping

### Lei 9.610/1998 — Direitos Autorais
**Art. 8º** — NÃO são objeto de proteção como direitos autorais:
- IV — **textos de tratados, convenções, leis, decretos, regulamentos, decisões judiciais e demais atos oficiais**

→ Cobre integralmente nosso corpus (leis, decretos, portarias, INs). **Sem barreira autoral para reprodução do texto integral.**

**Art. 46** — Limitações: autoriza reprodução de pequenos trechos em obras maiores, citação para estudo/crítica/polêmica, reprodução para uso pessoal sem fins lucrativos.

### Lei 12.527/2011 — LAI
- **Art. 7º** assegura acesso a informação produzida/custodiada por órgão público
- **Art. 8º §3º III** exige publicação em **formato aberto, estruturado, legível por máquina**, e permite **acesso automatizado por sistemas externos**

→ **LAI ampara explicitamente o scraping** de conteúdo público. Estamos exercendo direito constitucional/legal.

### Lei 13.709/2018 — LGPD
- **Art. 7º §4º**: dispensa consentimento para dados manifestamente públicos pelo titular, resguardados direitos e princípios da Lei.
- **Art. 4º II**: LGPD **não se aplica** ao tratamento exclusivamente acadêmico.

→ Atos normativos não contêm dados pessoais sensíveis. Riscos: páginas de programas que listam beneficiários por CPF/nome; editais com dados de servidores. **Mitigação obrigatória**: filtro PII (regex CPF/CNPJ) antes de armazenar.

### Lei 12.965/2014 — Marco Civil da Internet
Sem proibição direta a scraping. Obrigação de guarda de logs (art. 15) recai sobre provedor de aplicação, não sobre consumidor de dados públicos.

### Decreto 8.777/2016 — Política de Dados Abertos
Define dados abertos como "acessíveis ao público, formato aberto, processáveis por máquina, sob licença que permite livre utilização, **limitando-se a creditar autoria/fonte**". → Confirma que conteúdo gov.br = livre com atribuição.

## 4. Boas práticas técnicas — valores concretos

### User-Agent (obrigatório, identificável)
```
FRM-CatalogoPoliticas/0.1 (+https://github.com/<org>/<repo>; mailto:rogerio.barbosa@iesp.uerj.br) python-httpx/0.27
```
**NÃO** imitar navegador, **NÃO** esconder identidade, **NÃO** usar tokens "GPT/Claude/Bot/AI" (bloqueados em in.gov.br via robots.txt).

### Rate limiting

| Cenário | Valor | Justificativa |
|---|---|---|
| **Default global por domínio** | **1 req / 2s** (0.5 RPS) | Conservador; margem para gov.br instável |
| Quando robots.txt define crawl-delay | Respeitar (Senado = 10s) | RFC 9309 |
| Detectar 429/503 | Backoff exponencial: 2s, 4s, 8s, 16s, 32s + jitter ±25% | RFC 6585 |
| Honrar `Retry-After` | Sempre | RFC 6585 |
| Concorrência por domínio | **1 conexão simultânea**; até 5 domínios em paralelo | Evita ban |

### Timeouts e retries
- Connect: **10s**, Read: **30s** (gov.br pode ser lento), Total: **60s**
- 3 retries com backoff exponencial em transitórios (timeout, 5xx, 429)
- Não retry: 4xx (exceto 429), erros SSL não-recuperáveis (logar e seguir)

### TTL por tipo de documento

| Tipo | TTL | Justificativa |
|---|---|---|
| Lei federal vigente | **365d** | Mudam raramente; quando mudam é por nova lei |
| Decreto presidencial | **180d** | Mais rotativos |
| Portaria, IN | **90d** | Frequência mais alta de revisão/revogação |
| Página de programa governamental | **30d** | Conteúdo institucional muda frequentemente |
| PDF DOU específico (data fixa) | **infinito** | Edição diária imutável |

### Estratégia de revalidação
1. **HEAD primeiro** quando próximo do TTL: comparar `Last-Modified`/`ETag`
2. Se headers ausentes (comum em gov.br), GET completo + comparar SHA-256
3. Se mudou: armazenar nova versão, **manter versão anterior** com flag `superseded_at`

### Hash e versionamento
- **SHA-256** dos bytes brutos (não texto extraído)
- Path: `data/external_snapshots/<sha[:2]>/<sha>.<ext>`
- **Deduplicação automática** (se hash existe, não rebaixar)
- **Manter todas as versões** (espaço barato; auditoria histórica cara de reconstruir)
- Estimativa: 412 docs × média 2 versões/ano × 200KB médio = ~165MB/ano × 5 = 825MB. Trivial.

### Encoding
- Default: **UTF-8**
- Detecção: **`charset-normalizer`** (não GPL; vem com httpx/requests)
- Fallback: latin-1 (sites legados)
- Validação: se decode produz `�` > 1% → tentar fallback

### MIME detection
- **`puremagic`** > `python-magic` (libmagic não vem por padrão em Windows)
- Conferir contra `Content-Type` header; quando divergir, confiar no magic number

### Extração de texto

| Tipo | Stack | Configuração |
|---|---|---|
| HTML | **`trafilatura`** primeiro (F1=0.945); fallback `bs4 + lxml` | `trafilatura.extract(html, favor_recall=True, include_links=True, include_tables=True)` |
| PDF texto-nativo | **`pdfplumber`** (precisão + tabelas) ou `pypdf` (4× rápido sem tabelas) | Tentar pdfplumber; se vazio < 100 chars, pypdf |
| PDF escaneado | **`ocrmypdf`** + Tesseract `--language por` | Para corpus pequeno (<1000), OCR vale o esforço |
| DOCX | `python-docx` | Parágrafos + tabelas |
| DOC legado | `libreoffice --headless --convert-to txt` ou `antiword` | Comum em portais estaduais antigos |
| ODT | `odfpy` | Pouco frequente |
| TXT | leitura direta com encoding detection | — |

### Validação pré-armazenamento
1. Status HTTP final = 200
2. Tamanho ≥ 1KB (HTML), ≥ 5KB (PDF)
3. Sem regex de erro (`/(página\s+não\s+encontrada|erro\s+404|acesso\s+negado)/i`)
4. Para `lei`: deve conter `Art\.|Artigo`; para `portaria`: `PORTARIA\s+N`
5. Hash diferente do "erro padrão conhecido"

### Logs (JSONL)
Campos: `timestamp_iso, url_solicitada, url_final, http_status, content_type, sha256, tamanho_bytes, tempo_ms, encoding, validacao_passou, caminho_snapshot, retries, erro_tipo, erro_msg`

### Anti-detection: NÃO USAR
**Política explícita do projeto**: NÃO usar `cloudscraper`, `undetected-chromedriver`, rotação IP/proxies, fingerprint spoofing. Estamos coletando dados públicos para fins acadêmicos. Identidade transparente é a postura ética e legal correta.

| Função | Lib | Justificativa |
|---|---|---|

| HTML parsing | **`bs4 + lxml`** | lxml rápido; bs4 ergonômico |

| PDF text | **`pdfplumber`** | Melhor para tabelas (importante em normas) |
| PDF OCR | **`ocrmypdf`** | Wrapper estável Tesseract; gera PDF/A com camada de texto |
| DOCX | `python-docx` | Padrão de facto |
| ODT | `odfpy` | Único maduro |
| Encoding | **`charset-normalizer`** | Sem GPL; suficientemente preciso |
| MIME | **`puremagic`** | Zero deps (libmagic não garantido Windows) |
| Hash | `hashlib.sha256` (stdlib) | — |
| Logging | `structlog` ou stdlib `logging` em modo JSON | Estruturado para JSONL |

## 6. Riscos e mitigações

| Risco | Probabilidade | Impacto | Mitigação |
|---|---|---|---|
| IP ban por rate excessivo | Baixa (com defaults) | Alto | 0.5 RPS/domínio; `Retry-After`; backoff; UA identificável |
| Servidor lento/instável (gov.br) | Alta | Médio | Timeout 30s; 3× retry; salvar fila pendências |
| Conteúdo sensível (PII) | Média | Alto (LGPD) | Filtro regex CPF/CNPJ antes de salvar texto; log; nunca incluir "lista de beneficiários" |
| Mudança URL / link rot | Alta (gov.br migrou em 2020-2023) | Médio | Seguir redirects (5 max); URL final; revalidação mensal HEAD; Wayback Machine fallback |
| Página de erro retorna 200 | Média | Médio | Validações: tamanho, palavras-chave, regex erros |
| Direitos autorais terceiros embutidos | Baixa | Baixo | Uso citado em obra acadêmica é coberto art. 46 III |
| Norma revogada | Alta em 5 anos | Médio | Manter versão antiga + flag `revogada` + ID norma revogadora |
| Portal exige JavaScript | Baixa (portais antigos) | Médio | Fallback `playwright` só caso a caso; documentar exceção |
| Conteúdo grande (PDF DOU semanal) | Média | Baixo | Streaming download com size limit (alerta > 100MB) |
| Robots.txt mudando | Baixa | Médio | Cache robots.txt TTL 24h; logar mudanças |
| Bloqueio por UA com "bot/AI" | Confirmado in.gov.br | Alto | Nosso UA não contém esses tokens |

```markdown
# Captura Responsável

Regra-mãe para todo código que faz HTTP request a portal externo dentro do projeto FRM_CatalogoPoliticas. **Toda captura deve ser auditável, identificável, respeitosa e juridicamente fundamentada.**

## Princípios
1. **Transparência**: tráfego identificável nos logs do servidor remoto.
2. **Reprodutibilidade**: snapshot integral preserva o conteúdo no momento da captura.
3. **Cidadania de rede**: respeitar limites declarados (robots.txt, Crawl-delay, Retry-After) e implícitos (não hammer).
4. **Fundamento legal**: Lei 9.610/98 art. 8º IV, Lei 12.527/11 (LAI), Lei 13.709/18 (LGPD), Decreto 8.777/16 (dados abertos).

## Regras invioláveis

### R1. User-Agent identificável
Todo request DEVE enviar User-Agent: `FRM-CatalogoPoliticas/<versao> (+<url-projeto>; mailto:rogerio.barbosa@iesp.uerj.br) <client>/<versao>`
PROIBIDO: imitar navegador, ocultar identidade, usar tokens "GPT", "Claude", "Bot" (in.gov.br bloqueia).

### R2. Robots.txt
Antes de capturar URL de domínio novo, baixar e respeitar `<dominio>/robots.txt`. Cachear 24h.
- `Disallow` para nosso UA OU para `*` ⇒ pular URL, logar `bloqueado_robots`
- `Crawl-delay` ⇒ usar como intervalo mínimo. Senão default 2s.

### R3. Rate limiting
- Máximo: 1 conexão simultânea por domínio; 0.5 req/s (mais lento se Crawl-delay maior)
- Em 429/503: backoff exponencial (2,4,8,16,32s) + jitter ±25%; respeitar `Retry-After`
- Máximo 5 tentativas por URL antes de marcar falha

### R4. Timeouts
- Connect: 10s · Read: 30s · Total: 60s
- Em timeout: retry com backoff (R3)

### R5. Snapshot integral, content-addressable
Salvar bytes brutos em `data/external_snapshots/<sha256[:2]>/<sha256>.<ext>`.
Metadata em `data/extracted_text/<sha256>.metadata.json`.

### R6. Versionamento, nunca sobrescrever
Se nova captura tiver SHA diferente, criar novo snapshot e atualizar `superseded_by_sha256` no antigo. NUNCA deletar snapshot.

### R7. Validação obrigatória pré-armazenamento
- Status HTTP final = 200
- Tamanho ≥ 1KB (HTML) ou ≥ 5KB (PDF)
- Sem regex de página de erro
- Para `lei`: contém `Art\.|Artigo`. Para `portaria`: `PORTARIA\s+N`.
Se falhar: NÃO salvar como snapshot válido; logar `validacao_falhou`.

### R8. PII e LGPD
- ANTES de extrair texto: rodar regex CPF (`\d{3}\.\d{3}\.\d{3}-\d{2}`) e CNPJ (`\d{2}\.\d{3}\.\d{3}/\d{4}-\d{2}`)
- Se > 5 ocorrências: marcar `contem_pii=true`, NÃO incluir no corpus de análise. Snapshot bruto continua arquivado mas com flag.
- LGPD art. 4º II nos cobre como pesquisa, mas princípios de necessidade e segurança continuam aplicáveis.

### R9. Atribuição obrigatória em metadata
Campo `atribuicao` é obrigatório. Default por domínio:
- planalto.gov.br ⇒ "Brasil. Presidência da República. Casa Civil."
- gov.br ⇒ "Governo Federal — gov.br (CC BY-ND 3.0)"
- in.gov.br ⇒ "Diário Oficial da União — Imprensa Nacional"
- camara.leg.br ⇒ "Câmara dos Deputados"
- senado.leg.br ⇒ "Senado Federal"

### R10. Logs de captura
Cada request gera 1 linha JSONL em `logs/captura_<YYYY-MM-DD>.jsonl` com: `timestamp, url, url_final, status, sha256, bytes, ms, encoding, validou, caminho, retries, erro`.

### R11. Proibido
- Anti-detection (cloudscraper, undetected-chromedriver, fingerprint spoofing)
- Rotação de IP/proxy
- Capturar páginas que listem dados pessoais nominais como conteúdo principal
- Re-distribuir snapshot bruto sem cuidados (corpus interno, não republicado)

## Auditoria
Toda mudança nesta regra requer revisão humana e atualização da skill `capturar-norma`. Versão atual: 0.1 · 2026-05-01.
```

```markdown
# Skill: capturar-norma

Implementa de ponta a ponta o protocolo de `rules/captura-responsavel.md`.

## Pré-requisitos
- Stack Python: `httpx`, `trafilatura`, `pdfplumber`, `ocrmypdf`, `python-docx`, `puremagic`, `charset-normalizer`, `tenacity`, `pydantic`
- `tesseract` no PATH (OCR PDFs escaneados)
- Diretórios: `data/external_snapshots/`, `data/extracted_text/`, `logs/`

## Algoritmo (11 etapas)

Entrada: `link_id` (do registry) + `url` + `tipo_documento_esperado`.

1. **Pre-flight**: validar URL, resolver domínio, carregar robots.txt (cache 24h), checar Disallow, capturar Crawl-delay
2. **Aguardar slot**: consultar timestamp do último request ao domínio; aguardar intervalo mínimo + jitter ±25%
3. **HEAD request** (opcional, se snapshot anterior existir): comparar Last-Modified/ETag; se inalterado, atualizar `ultimo_visto` e sair
4. **GET request**: headers UA (R1), Accept apropriado, Accept-Encoding gzip; timeout 10/30/60; seguir redirects (5 max); registrar URL final; em 429/503 backoff
5. **Validação bruta**: status final = 200, bytes ≥ mínimo por tipo, MIME bate com Content-Type
6. **Hash + dedupe**: sha256 dos bytes; se snapshot existe, atualizar `ultimo_visto` e sair
7. **Salvar snapshot**: persistir bytes em `data/external_snapshots/<sha[:2]>/<sha>.<ext>`; detectar encoding via charset-normalizer
8. **Extração de texto** (por tipo): trafilatura para HTML; pdfplumber para PDF (fallback ocrmypdf se vazio); python-docx para DOCX; libreoffice para DOC; odfpy para ODT
9. **Validação do extraído**: sem regex de erro; palavras-chave esperadas (Art., PORTARIA); PII scan (CPF/CNPJ); se falhar, marcar `validacao_falhou`
10. **Metadata e log**: compor `<sha>.metadata.json`; atualizar `data/registry.parquet`; append linha JSONL em `logs/captura_<data>.jsonl`
11. **Retorno**: dict `{status, sha256, caminho_snapshot, texto_path, validacao}`

## Erros e exits
- `bloqueado_robots`: não reagendar
- `falha_status`: reagendar 24h
- `falha_rede`: reagendar 1h
- `validacao_falhou`: snapshot existe mas suspeito; revisão manual
- `pii_alerta`: snapshot com PII acima do limiar; revisão

## Política de re-execução
- Lei federal: 365d
- Decreto: 180d
- Portaria/IN: 90d
- Página de programa: 30d

## Conformidade
Esta skill implementa R1-R11 de `rules/captura-responsavel.md`. Toda alteração de comportamento exige bump de versão e revisão humana.
```
